# Глоссарий AEM (Ubiquitous Language)

## Описание

Единый язык проекта **AEM** (Anime Epic Moments): сокращения, доменные сущности
и технические понятия. Один термин означает одно и то же в коде, документации,
задачах и разговорах с заказчиком. Если термин расходится с этим документом, прав
термин, а документ нужно обновить.

Правило именования: сущности предметной области называются так же, как классы в
`src/backend/domain/` (с поправкой на русский язык объяснения).

## Как это работает

### Сокращения

| Термин | Расшифровка | Значение в AEM |
| --- | --- | --- |
| **AEM** | Anime Epic Moments | Проект, платформа и кодовая база целиком. Единственное допустимое сокращение названия |
| **DIP** | Dependency Inversion Principle | Принцип инверсии зависимостей: внешние слои зависят от абстракций внутренних, а не наоборот |
| **IoC** | Inversion of Control | Инверсия управления: объект не создаёт зависимости сам, их передаёт контейнер |
| **DI** | Dependency Injection | Внедрение зависимостей; в AEM реализовано библиотекой Dishka |
| **UoW** | Unit of Work | Единица работы: граница транзакции, выдающая репозитории и фиксирующая изменения атомарно |
| **VO** | Value Object | Неизменимый объект-значение без идентичности (`frozen` dataclass) |
| **DTO** | Data Transfer Object | Объект передачи данных между слоями: `Command`, `Query`, результат сценария |
| **LLM** | Large Language Model | Языковая модель, превращающая описание на естественном языке в поисковые запросы |
| **HLS** | HTTP Live Streaming | Формат потокового видео (плейлист `.m3u8` + сегменты); основной формат источников AEM |
| **CSRF** | Cross-Site Request Forgery | Межсайтовая подделка запроса; в AEM закрыта токеном в сессии |
| **JWT** | JSON Web Token | Подписанный токен доступа и обновления сессии |
| **CSP** | Content Security Policy | Политика безопасности содержимого в заголовках ответа |
| **SSR** | Server-Side Rendering | Серверный рендеринг: провайдер, у которого данные извлекаются из HTML-страницы, а не из JSON API |
| **ADR** | Architecture Decision Record | Запись об архитектурном решении в формате MADR |
| **MADR** | Markdown ADR | Шаблон ADR: контекст, решение, альтернативы, последствия |
| **CI** | Continuous Integration | Пайплайн проверок в `.github/workflows/ci.yml` |

### Доменные сущности

| Термин | Определение | Где живёт |
| --- | --- | --- |
| **Title** (Тайтл) | Аниме-сериал, фильм или OVA как единица каталога. В коде — сущность `Anime`: название, оригинальное название, год, жанры, рейтинг, постер | `domain/entities/anime/` |
| **Episode** (Эпизод) | Конкретная серия тайтла. В AEM не является отдельной таблицей: номер серии — целочисленное поле `episode` у источников, хайлайтов и сессий | `episode: int` в сущностях |
| **Moment** (Момент) | Отрезок времени из эпизода тайтла с описанием и метаданными. Две формы: **viewing moment** — черновик кадра, снятый во время просмотра; **highlight** — опубликованный момент с таймкодами `start`/`end` | `domain/entities/moment/`, `domain/entities/highlight/` |
| **Highlight** (Хайлайт) | Опубликованный момент: таймкоды начала и конца, заголовок, категория, эмоция, флаг спойлера, счётчики лайков и просмотров. Основная публичная единица контента AEM | `domain/entities/highlight/`, `domain/aggregates/highlight/` |
| **Highlight context** (Контекст хайлайта) | Привязка хайлайта к источнику просмотра, озвучке и названию тайтла — чтобы зритель открывал момент в том же плеере и той же озвучке | `domain/value_objects/highlight/` |
| **Collection** (Коллекция) | Пользовательская подборка тайтлов с названием, описанием и признаком публичности. Агрегат: коллекция и её элементы меняются согласованно | `domain/aggregates/collection/` |
| **Favorite** (Избранное) | Закладка тайтла пользователем с локальным снимком карточки (название, постер, жанры), чтобы список не зависел от внешнего каталога | `domain/entities/favorite/` |
| **Rating** (Оценка) | Оценка тайтла пользователем по десятибалльной шкале | `domain/entities/rating/` |
| **Reaction** (Реакция) | Эмоциональная реакция пользователя на эпизод тайтла | `domain/entities/reaction/` |
| **Viewing session** (Сессия просмотра) | Состояние плеера: позиция в секундах, громкость, качество, пауза. Нужна для продолжения просмотра с того же места | `domain/entities/watch/` |
| **User anime status** (Статус тайтла) | Прогресс пользователя по тайтлу: смотрю, просмотрено, отложено, брошено | `domain/value_objects/watch/` |
| **Translation** (Озвучка) | Логический вариант перевода: название озвучки, тип (озвучка, субтитры), язык | `domain/entities/watch/` |
| **Watch source** (Источник просмотра) | Конкретный воспроизводимый источник серии: провайдер, озвучка, качество, ссылка на поток. AEM хранит ссылки, но не видеофайлы | `domain/entities/watch/` |
| **Provider** (Провайдер) | Внешний сервис-источник контента: Kodik, AniLibria, AnimeGo, Kinobox, HDRezka, SameBand, AniBoom, Hanime, Hentaigasm, Eporner, YouTube, JustWatch | `application/interface/services/watch_source_provider.py` |
| **Ephemeral links** (Разовые ссылки) | Признак провайдера, чьи ссылки протухают: такие источники перезапрашиваются, а прежние записи удаляются перед записью новых | `WatchSourceProviderInterface.ephemeral_links` |
| **Media Proxy** (Медиа-прокси) | Внутренний сервис AEM, отдающий HLS-поток провайдера через собственный домен — ради CORS, скрытия реферера и защиты прямых ссылок | `infrastructure/external/video/hls_proxy/` |
| **Smart Search** (Умный поиск) | Поиск тайтлов и моментов по смысловому описанию на естественном языке: LLM собирает поисковые запросы, каталог выполняет поиск | `application/use_cases/anime/` |
| **Taste profile** (Вкусовой профиль) | Сводка вкусов пользователя по его просмотрам, оценкам и избранному; служит входом для рекомендаций | `domain/value_objects/recommendation/` |
| **Recommendation** (Рекомендация) | Предложение тайтла с оценкой релевантности и объяснением, почему он подходит | `domain/value_objects/recommendation/` |
| **Support ticket** (Обращение в поддержку) | Сообщение пользователя с темой и текстом, уходящее в Telegram и на почту | `domain/entities/support/` |
| **Feature flag** (Фиче-флаг) | Переключатель поведения, который клиент читает через `GET /api/v1/config` | `config/sections/features.py` |

### Термины слоёв и инфраструктуры

| Термин | Определение |
| --- | --- |
| **Domain** (домен) | Чистое ядро: сущности, value objects, политики, исключения. Без фреймворков, базы и сети |
| **Application** (прикладной слой) | Сценарии (use cases) и порты. Оркестрирует домен, но не знает, кто именно реализует порт |
| **Infrastructure** (инфраструктура) | Адаптеры: SQLAlchemy-репозитории, клиенты внешних API, Redis-кэши, DI-провайдеры |
| **Presentation** (представление) | FastAPI-роуты, схемы запросов и ответов, HTML-шаблоны. Только переводит HTTP в вызов сценария и обратно |
| **Use case** (Сценарий) | Класс с методом `execute`, реализующий один вариант использования: «добавить в избранное», «собрать страницу просмотра» |
| **Command / Query** | DTO на входе сценария: `Command` меняет состояние, `Query` только читает |
| **UseCaseResult** | Единый результат сценария: `ok`, `status_code`, `data`, `error`. Избавляет представление от разбора исключений |
| **Port** (Порт) | Абстракция в `application/interface/`: репозиторий, сервис, LLM-клиент, единица работы |
| **Adapter** (Адаптер) | Реализация порта в `infrastructure/` |
| **Repository** (Репозиторий) | Адаптер доступа к данным одной зоны домена; выдаётся единицей работы |
| **Unit of Work** | Граница транзакции. Вход в контекст (`async with uow`), работа через репозитории, коммит при успехе и откат при исключении |
| **Mapper** (Маппер) | Перевод HTTP-формы или тела запроса в `Command`/`Query` с валидацией |
| **Response model** | Pydantic-схема ответа JSON API; входит в контракт OpenAPI |
| **Page** (Страница) | HTML-ответ, отрисованный Jinja2-шаблоном; JSON-клиенты получают те же данные через `/api/v1/...` |
| **ErrorResponse** | Стандартное тело ошибки JSON API: код, сообщение и HTTP-статус |
| **Scope** (Область) | Время жизни зависимости в Dishka: `APP` — на процесс, `REQUEST` — на один HTTP-запрос |
| **TTL cache** | Кэш с временем жизни записи: результаты поиска, карта доступности озвучек, рекомендации |
| **Rate limit window** | Окно ограничения частоты запросов в секундах (`AUTH_WINDOW_SECONDS`, `HIGHLIGHT_RATE_WINDOW_SECONDS`) |
| **Bearer scheme** | Мобильная схема доступа: пара токенов в теле ответа и заголовок `Authorization: Bearer` для запросов |
| **Cookie scheme** | Браузерная схема доступа: HttpOnly-cookie `access_token` и `refresh_token` плюс CSRF-токен |

## Почему это сделано так

- Термины фиксируют границы: `Translation` и `Watch source` разделены, потому что
  «озвучка» и «конкретная ссылка на поток» живут по разным правилам — озвучка
  стабильна, ссылка протухает.
- `Highlight` и `Viewing moment` разделены намеренно: черновик кадра не должен
  попадать в публичную ленту.
- В глоссарии нет терминов, которых нет в коде: описание сущности, которую нельзя
  найти в `src/backend/domain/`, вводило бы читателя в заблуждение.

## Где в коде

- `src/backend/domain/__init__.py` — публичный экспорт доменных типов
- `src/backend/domain/entities/` — сущности по зонам
- `src/backend/domain/value_objects/` — value objects по зонам
- `src/backend/domain/policies/` — доменные политики и правила
- `src/backend/application/interface/` — порты репозиториев, сервисов и единицы работы
