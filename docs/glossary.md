# Глоссарий

## Описание

Этот глоссарий фиксирует ключевые термины, которые используются в продукте, кодовой базе и документации.

## Как это работает

- Anime: объект с метаданными тайтла, приходящий от внешних провайдеров
- Favorite: закладка пользователя на аниме, сохраненная вместе с локальным snapshot-описанием
- Highlight: пользовательский момент из эпизода, заданный диапазоном времени
- Highlight context: данные из плеера, прикрепленные к хайлайту, например перевод и источник просмотра
- Watch source: конкретный воспроизводимый источник от провайдера для эпизода
- Translation: логический вариант озвучки или субтитров, который группирует watch sources
- Viewing session: сохраненное состояние плеера для продолжения просмотра
- User anime status: пользовательский статус тайтла
- Recommendation: ранжированная рекомендация, собранная из избранного и хайлайтов
- Provider: внешняя интеграция вроде Jikan, AniList, Kodik, AniLibria, YouTube или JustWatch
- Use case: одно прикладное действие, вызываемое из routes
- Presentation layer: FastAPI routes и формирование ответов
- Infrastructure layer: репозитории, база, внешние клиенты, кэши и security-хелперы

## Почему это сделано так

- общий словарь убирает неоднозначность между routes, сервисами, тестами и документацией
- проект смешивает продуктовые и интеграционные термины, поэтому явные определения обязательны
