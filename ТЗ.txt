Впринципе можешь работать субагентами, одновременно анализируя и проект и документацию это ускорит время выполнения а не, теперь могу, только у меня не тянуться озвучки которые я хочу  Проблема с получением токена Kodik — классическая ситуация для разработчиков:
Kodik уже давно закрыл свободную регистрацию и выдает токены только вручную

Детальный разбор лучших вариантов для вашей задачи

Если цель — получить максимум любительских озвучек (Onwave, Комната Диди и др.)
без возни с регистрацией, лучше всего комбинировать следующие подходы:

1. Использование Kinobox (Самый быстрый старт без токенов)

Kinobox — готовый JS-скрипт, который встраивается в HTML/React/Vue. Он сам
опрашивает базы Kodik, HDRezka, Alloha, Collaps и строит плеер с выбором
источника и озвучки.

  - Как работает: Вы передаете ему Shikimori ID или Kinopoisk ID тайтла.
  - Код подключения:

<div class="kinobox_player"></div>
<script src="https://kinobox.tv/kinobox.min.js"></script>
<script>
    kbox('.kinobox_player', {
        search: { shikimori: '5114' }, // ID аниме (например, Fullmetal Alchemist)
        menu: { default: 'menuList' }
    });
</script>

2. Публичные токены Kodik (Официальная база без регистрации)

В открытых репозиториях GitHub (таких как расширения для Shikimori, плагины для
Kodi и открытые плееры) в открытом виде лежат валидные токены Kodik для чтения
API (search, list).

  - Как искать: В поиске GitHub введите: kodik token api или kodik.biz/search
    token.
  - Пример запроса к API:

POST https://kodikapi.com/search
Content-Type: application/x-www-form-urlencoded

token=ПУБЛИЧНЫЙ_ТОКЕН&shikimori_id=5114&with_episodes=true

В ответе вы получите полную структуру серий со всеми студиями (включая Onwave и
Комнату Диди) и прямые ссылки на iframe.

3. Парсер AnimeGo / AniBoom

AnimeGo — главный агрегатор фандаба в РФ. Все озвучки хранятся у них в
стандартизированном виде через плееры AniBoom и Sibnet.

  - Вы парсите страницу animego.org/anime/slug -> получаете вкладки озвучек.
  - При клике на серию уходит AJAX-запрос к их внутреннему API, возвращающий
    iframe плеера.

4. Неофициальный API HDRezka

HDRezka хранит сотни озвучек и отдает прямые .m3u8 ссылки (видеопотоки можно
крутить в собственном кастомном плеере вроде Video.js или Plyr без сторонних
баннеров).

  - На GitHub есть десятки готовых библиотек (ищите: hdrezka-api,
    rezka-stream-extractor на Python / Node.js).
  - Позволяет выбирать студию озвучки, сезон, серию и разрешение (от 360p
    до 1080p Ultra).

Архитектурная рекомендация для вашего проекта

Чтобы проект не зависел от одного балансера (если Kodik или Rezka упадут):

1.  Метаданные (постеры, описания, списки серий, ID): берите из официального
    бесплатного Shikimori API (shikimori.one/api/doc).
2.  Основной плеер редких озвучек: настройте интеграцию через Kinobox или
    запросы с публичным токеном Kodik.
3.  Плеер высокого качества (чистый стрим без рекламы): подключите AniLibria API
    (для максимального качества серий от Либрии) + HDRezka Scraper для остальных
    популярных студий.
 отсюда ты можешь взять чтото прям мега классное и внедрить в проект
